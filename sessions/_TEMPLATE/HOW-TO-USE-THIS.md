# How to use this template

All ten session folders already exist in [`sessions/`](..), each with its own `README.md` and
`readings.md`. You should not need this template.

It is here for the next time the course runs, or if a session gets added. Copy `README.md` and
`readings.md` into the new folder and fill in the placeholders.

Folder names are `NN_YYYY-MM-DD_short-topic`, so the web interface lists them in teaching order.
